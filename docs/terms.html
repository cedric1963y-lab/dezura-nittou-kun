プレミアム（自動更新サブスクリプション）

  • サブスクリプショングループ: 出面・日当くん Premium
  • 月額: ¥100（1か月ごとに自動更新）
  • 年額: ¥1,200（1年ごとに自動更新）
  • 無料体験: 月額・年額とも、はじめての方は1週間無料（対象の Apple ID のみ）

表示価格は日本の価格です。実際に請求される金額は、購入画面に表示される金額です。

お支払いは購入を確定した時点で Apple ID に請求されます。無料体験の対象の場合は、無料期間が終わった時点で課金が始まります。無料期間が終わる24時間以上前に解約すれば請求されません。現在の期間が終わる24時間以上前に解約しない場合、同じ期間・同じ価格で自動更新され、更新料は期間が終わる前の24時間以内に請求されます。

管理と解約は、iPhone の「設定」> Apple ID >「サブスクリプション」から行えます。解約後も、その期間の終わりまではプレミアムを使えます。返金は Apple の基準に従います。

無料プランとプレミアムの違い

無料プランでは、職人 2 人・現場 1 か所まで登録でき、今月の出面と集計、LINE 用テキストの送信が使えます。プレミアムでは、職人・現場の数の上限がなくなり、過去の月の出面と集計、出面表 PDF と CSV の書き出しが使えます。

契約が終わっても、付けた出面・名簿・現場は消えません。無料プランの範囲を超えて登録済みの職人や現場も、そのまま残ります。

免責

本アプリの集計は、入力された出面と日当をもとにした計算です。給与・請求の最終確認は利用者が行ってください。
