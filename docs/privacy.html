出面・日当くん

プライバシーポリシー

対象は iPhone アプリ「出面・日当くん」（Bundle ID jp.dezura.app）です。最終更新: 2026年10月8日。

出面・日当くん（以下「本アプリ」）は、入力された出面・職人の名前と日当・現場名を、この iPhone の中だけに保存します。

  • アカウント登録はありません
  • 運営のサーバーへ、出面・名簿・現場・購入情報を送りません
  • 広告 SDK、解析 SDK は入れていません

収集する情報

開発者が利用者の情報を収集することはありません。入力した職人の名前や日当は、本アプリの集計と、利用者が自分で操作した共有（LINE、メール、ファイルなど）にだけ使われます。共有した先での扱いは、共有先のサービスの方針に従います。

トラッキングと広告

トラッキングはしません。広告識別子も、AdMob などの広告 SDK も使いません。このウェブページも、解析用のスクリプトや第三者への送信をしません。

購入

購入と契約の確認は Apple の App Store（StoreKit）が行います。本アプリは契約の種類と有効期限だけを端末内に控えます。支払い情報を本アプリや開発者が受け取ることはありません。

バックアップと削除

iPhone のバックアップをオンにしている場合、Apple のバックアップに本アプリのデータが含まれることがあります。本アプリを削除すると、端末内のデータも消えます。

使わない権限

位置情報、カメラ、写真、連絡先、マイク、健康情報は使いません。
