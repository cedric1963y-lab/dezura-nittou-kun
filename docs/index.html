出面・日当くん

サポート

対象は iPhone アプリ「出面・日当くん」（Bundle ID jp.dezura.app）です。最終更新: 2026年10月8日。

一人親方や少人数の職長向けの出面・日当アプリです。誰がどの日にどの現場に出たかをタップで付けて、月末に人工と日当の合計を出し、LINE や PDF で送れます。アカウントはありません。

使い方

  1. 「名簿」で職人（自分も含む）と日当、現場を登録する。残業単価は任意です。
  2. 「出面」で日付を選び、職人をタップする。1回目で 1人工、2回目で半日（0.5人工）、3回目で取り消しです。「全員 1人工」で一度に付けられます。
  3. 別の現場や残業は、職人の右にある「…」から入れる。
  4. 「集計」で職人別・現場別の人工と日当を確認し、LINE 用テキスト、出面表 PDF、CSV で送る。

日当を変えたときは、今月 1 日以降の出面に反映されます。先月までの金額は変わりません。

無料とプレミアム

無料では職人 2 人・現場 1 か所まで登録でき、今月の出面と集計、LINE 用テキストの送信が使えます。

プレミアムは月額 ¥100、または年額 ¥1,200 の自動更新サブスクリプションです（はじめての方は1週間無料）。職人と現場が無制限になり、過去の月の出面と集計、出面表 PDF と CSV の書き出しが使えます。解約しても、付けた出面は iPhone の中に残ります。広告はありません。

支払いや解約の条件は 利用規約 に書いてあります。購入の復元は、アプリの「設定」→「プラン」→「購入を復元」です。

データの扱い

出面・名簿・現場は、この iPhone の中だけに保存します。運営のサーバーへは送りません。詳しくは プライバシーポリシー です。
